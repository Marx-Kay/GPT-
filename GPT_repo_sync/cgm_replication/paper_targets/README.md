# CGM 出版图中的可核对目标

来源为本地 `cgm.pdf`，Figure 2A 为 PDF 第12页/印刷页502，Figure 3 为 PDF 第15页/印刷页505。本目录仅提取论文图形，不修改模型或原始 Matlab/Fortran 源码。

## 文件

- `figure3_annual_targets.csv`：图3A消费、收入、财富与图3C股票份额的均值/5%分位/95%分位，按整数年龄线性插值。消费、收入、财富单位为1992年千美元；股票份额为0至1。
- `figure3_raw_vector_points.csv`：同一图形的原始PDF矢量坐标、drawing index与换算后坐标。
- `figure3_extraction_metadata.json`：轴刻度、坐标变换、来源SHA-256、原始点数和支持区间。
- `figure3_extracted.png`：从矢量点重画的3A/3C，用于对照原图进行视觉验证。
- `figure2a_age99_targets.csv`：图2A、99岁股票份额；横轴为 cash-on-hand（千美元），不是扣除消费后的储蓄。
- `figure3b_npv_income_targets.csv`、`figure3b_npv_to_wealth_targets.csv`：图3B左右轴曲线，横轴按印刷年龄标签校准，不能直接作为已确定聚合口径的模型目标。
- `*_raw.csv` 和 `additional_extraction_metadata.json`：2A/3B的原始矢量与轴信息。
- `income_calibration_check.csv`：图3A平均收入与原始校准函数加累计永久冲击的lognormal均值校验。
- `extract_figure3.py`、`extract_additional.py`：可重复运行的提取脚本。

这些是出版图的**近似读数**，不是作者模拟原始数据。实线使用路径顶点；虚线、点线使用组成虚线的填充多边形中心。轴变换由全部有标签的刻度拟合；不把图框上界错误地当作1.0。图3C上边框换算为1.0993，1.0是内部网格线。图2A同样有1.1左右的留白。

建议比较容差：财富±2千美元，收入/消费±1千美元，股票份额±0.01，年龄±0.15年。CSV中的小数位只保留计算结果，不代表论文提供相应精度。虚线端点超出可识别中心点支持区间时留空，不作外推。实线的极小坐标量化偏差允许0.06年边界误差。

## 可确认的校准与解释

正文§3和表4说明基准为第二教育组（高中毕业、无大学学位），相对风险厌恶10、折现因子0.96、无遗赠、无风险总收益1.02、股票总收益均值1.06、标准差0.157、永久对数收入创新方差0.0106、暂时方差0.0738、与股票回报相关系数0。收益是正态的算术收益创新，不是对数收益创新。

方程(2)-(3)规定对数永久收入是随机游走；创新均值是零。因而水平收入有lognormal均值增长，不能自动减去半方差后还声称完全保留了原文过程。方程(5)规定65岁为最后工作期，退休收入在其后按最后一期永久收入的0.68212固定。表2的年龄二次项除10、三次项除100；表1的常数与表2年龄多项式常数共同决定收入水平。

原始校准的确定性收入在50岁为27.61千美元；加累计永久冲击及暂时冲击的均值修正后约33.8千美元，图3A为33.57千美元。退休后模型平均收入约21.59千美元，图3A约21.69千美元。因此图3A收入水平支持累计永久冲击的解释，差距不是把几百美元误认成几千美元造成的。

图3A在起点附近的收入约16.41、消费约13.77，图中财富约2.5至3；收入减消费约2.64。该图的财富年龄标记可能对应消费后储蓄或下一期资产，但正文没有明确给出模拟初始条件。这是有待核对的时点差，不能据此擅自重定义主模型，也不足以解释大幅财富峰值差距。

## 图3B应保留的口径不确定性

1. 图3B的年龄文字标签位于相邻刻度中间；例如20岁标签中心为PDF x=109.94，而图框左边/首刻度为x=102.62。按所有印刷标签拟合，实线从约18.07岁开始，至98.07岁结束。因此本目录按文字标签记录，不把第一根刻度强行设为20岁。该排版/时点偏移需要与作者绘图代码核对。
2. 图注把比率分母称为financial wealth；§4.1相邻正文称为cash-on-hand。两者的区别需要显式说明。
3. 正文§5.2（PDF33/印刷523）明确说明，无劳动收入风险的规则(12)按无风险利率且调整死亡率折现未来工资；这一段直接解释的是替代投资规则，尚不能仅凭这段话断定图3B采用完全相同的具体计算。
4. 图中可能画横截面比率均值 `E[H/W]` 或 `E[H/X]`，而非 `E[H]/E[W]` 或 `E[H]/E[X]`。例如65岁左右图示PV约349.53、比率约5.47，不能仅因与均值之比不同就判定图错；异质性与聚合方式足以影响比较。因此这些曲线保留为出版图对照，应在确认聚合定义后才作为模型验收依据。
