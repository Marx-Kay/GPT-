# CGM Python 版本独立审查意见

审查日期：2026-09-10。审查范围：用户提供的 cgm_python、cgm_replication_python、项目现状与结论_给老师看.md；对照 GPT_repo_sync 的 Matlab 源码及本地两篇论文原文。原提交文件未改写，本目录另存审查和复验结果。

## 一、给非专业读者的结论

DeepSeek 确实写出了可运行的 Python 求解器，并做了网络拟合。当前源码重跑得到财富峰值 180.542 千美元，与保存的结果一致。这部分不是凭空编造的数字。

但是，“数字能重跑”和“求解了论文规定的问题”是两项不同的验收。本次发现数处直接改变模型或最优条件的错误，并通过解析反例确认了错误的实际影响。因此，不能采用原汇报中的以下说法：

- “180左右是模型真正的解，已经证明原 Matlab 算错。”
- “财富差21%属于正常复现误差，定性完全成功。”
- “21维实验直接证明缓解了高维生命周期模型的维数灾难。”
- “完整连续时间 CGM 已经由神经网络求解。”

我们此前的 Matlab 版也没有完全匹配论文出版结果，433 千美元仍是待解释的结果。本次审查并没有证明它毫无错误；结论是 DeepSeek 这套实现不能作为推翻 Matlab 的有效证据。

## 二、逐项比较：参数接近，实际模型不同

两版多数标量参数一致：gamma=10、beta=.96、无风险总收益1.02、股权溢价.04、股票波动率.157、永久收入方差.0106、暂时收入方差.0738、退休替代率.68212。Python 收入多项式常数项为 .5304，原模板是 .530339；这个小差别不能解释主要偏差。

### 1. Python 额外强制“消费不超过储蓄”

位置：discrete/cgm_model.py 第57–60行。

这里 a 是消费后的储蓄网格，程序先计算消费 ct，再执行 ct=min(ct,a)，最后令现金 x=a+ct。因此所有非终期节点都满足 c/x≤1/2，线性插值也继承这一限制。

论文限制是消费不超过现金，即 c≤x、不能借款。论文没有要求消费不能超过储蓄。正确 EGM 中应在零储蓄处保留正消费的边界节点；该程序反而把零储蓄处消费设为0。

独立解析检验：取99岁，只剩当前及100岁终期；消除股票收益随机性，保留养老金 .68212、生存概率 .6809、贴现 .96、无风险总收益1.02。终期消费全部现金。解析最优消费为

$$
c^*(x)=\min\left[x,\frac{R_fx+\lambda}{R_f+(\beta p R_f)^{1/\gamma}}\right].
$$

| 当前现金 x | 解析消费 | Python 实际消费 |
|---:|---:|---:|
| 0.5 | 0.500000 | 0.250000 |
| 1 | 0.859537 | 0.500000 |
| 2 | 1.374617 | 1.000000 |
| 5 | 2.919858 | 2.500000 |

该反例不依赖 Matlab，也不依赖从论文图片读取数字。程序连这个简化问题都没有解对，不能称为通过了最优性验收。当前完整模拟20岁平均消费8.187、收入16.412，消费约占收入49.9%，与汇报中“年轻时消费紧跟收入”的叙述冲突。

### 2. 永久冲击与暂时冲击被设成完全正相关

位置：discrete/cgm_model.py 第37–38行。

G和Y都使用同一个zy节点，相当于两个对数冲击的相关系数为1。CGM正文第1.1.2节、式(2)–(3)明确写永久创新与暂时冲击不相关。本程序对应协方差0.027969，而论文要求0。

模拟器第72行又分别抽取独立的 e_eps 和 e_u，因此求解时认为的收入风险与模拟时真正经历的风险也不一致。

### 3. 消费 Euler 方程遗漏永久收入尺度

位置：discrete/cgm_model.py 第56行。

对论文模型做永久收入归一化后，工作期正确的内点条件为

$$c_t^{-\gamma}=\beta p_t E[(G_{t+1}c_{t+1})^{-\gamma}R^p_{t+1}].$$

Python 只用了 c_next^(-gamma)，漏掉 G^(-gamma)。Matlab cgm_solve.m 第30、34行使用 (G.*cn).^(-gamma)，在这一项上与上述推导一致。

这不是“换一个时点约定”就自然等价的差异。时点和单位变化必须同步改变收入、状态、归一化及模拟递推。

### 4. 股票决策最大化的对象不对

位置：discrete/cgm_model.py 第46–49行。

程序比较的是下一期消费的一期效用 U(c_next)，没有保存或评价完整下一期值函数，也没有工作期的 G^(1-gamma) 倍率。一般生命周期问题应最大化完整延续价值，或依据包络条件求股票一阶条件。只有非常特殊的终期等情形，下一期消费效用才等于完整延续价值。

### 5. 所谓独立诊断并不构成充分证明

- test_euler_consistency.py 用平均消费增长与确定性 Euler 增长率比较。有收入和收益风险时，Euler 条件是关于随机边际效用的条件期望，不能用平均消费的增长比代替。
- bellman_test2.py 的政策评价仍缺少 G^(1-gamma)，并再次共用收入冲击节点。用另一条错误递推验证，不能验证论文模型。
- 同一文件“复刻 Matlab”时把特征向量首行当成正态节点。原 Matlab 的节点是特征值，首行特征向量的平方是权重，二者不可互换。
- 仅报告绝对 Bellman 值差10^-5并不足以证明误差很小。gamma=10时值函数尺度随财富剧烈变化，应报告有经济含义的相对误差、政策改进或福利误差。
- 网格加密后结果稳定，只能排查部分离散误差；错误模型也可能稳定收敛。

## 三、报告与对照表中的具体错误

1. replication_scorecard.csv 和 figure3_comparison_table.csv 将旧 Matlab 的65岁股票份额写成418.93，实际读到了储蓄列。scorecard.py 中明确把第五列命名为alpha，而原CSV第五列是储蓄，第六列才是alpha。make_figure.py 当前映射已不同，说明脚本与存量输出还存在版本同步问题。
2. 给老师看的文字把旧 Matlab 股票曲线 RMSE 写成 .004；此前 metrics.json 中 Figure 3 的股票份额RMSE是 .284518。.00431对应99岁 Figure 2A政策函数，不能跨图使用。
3. “论文在同一状态上的消费/收入”不能直接由Figure 3平均生命周期路径充当。平均消费/平均收入不等于在任意指定现金状态上的条件政策值。
4. CGM原文 Table 6基准行依次为：100-age .637；No income 1.531；No income risk .152；Zero 2.108；Approx .084。给老师看的文稿将“忽略收入”写成2.108，混淆了两列。我们此前只比较四种规则，也不能声称已完整覆盖五列。
5. 股票份额年轻期偏差几十个百分点以及财富差21%，都没有一个可直接称为“正常误差”的统一标准。应说明未匹配并解释误差来源。
6. 当前 cgm_python 只含结果文件；求解源码在 cgm_replication_python/discrete。多个诊断仍从旧 cgm_python 路径导入并引用 /tmp/cgmwork，直接照README运行未必可重现。本次通过显式加载当前源文件完成重跑，未使用旧临时依赖。

## 四、机器学习究竟完成了什么

### Merton所谓21维实验

adaptive/dpi_scaling.py 第60–61行直接使用

    A = M.MERTON_K ** (-M.GAMMA)
    V = -A * w.pow(1 - M.GAMMA) / (M.GAMMA - 1)

这是已知解析值函数，既没有让网络学习其形状，也没有学习系数A。网络只输出消费比和股票份额，股票份额的输出偏置还使用了解析最优值初始化。新增20个状态不进入效用、收益和财富动态，因而实际经济问题仍是一维。

实验可以作为“给定解析值函数时恢复控制变量、网络忽略无关输入”的初步检查。不能由此断言解决了有效21维问题。把这种一维可约问题与40^21的机械张量网格比较，夸大了必要计算成本；合理基准首先会消除无关维度。

### 生命周期网络

nn_policy_fit.py 用上述离散网格政策作训练标签。这是监督拟合/政策蒸馏，不是独立解连续时间HJB，也没有消除获取标签所需的网格求解成本。

保存的 JSON 中消费比最大误差约 .01967，股票份额最大误差 .16740，即16.74个百分点。报告只突出消费比误差，漏掉了这个更大的股票控制误差。代码在全部训练点上计算这些拟合误差，没有独立样本外政策误差验收。

### 连续时间模型

ct_model.py 虽声明永久收入扩散SIGMA_P，但 drift_diffusion 没有把它加入归一化财富的扩散，也没有相应的Ito漂移修正；一维时收入项直接为0。文件说明中的HJB还缺少生命周期年龄导数，以及永久收入齐次变换后的相关项。不能把此文件称为已经验证的完整CGM连续时间模型。

用户给的RFS原文作者是 Victor Duarte、Diogo Duarte、Dejanir H. Silva，共三人，没有Saporito。其方法明确包含值函数的政策评价及政策改进，并用经济上有效的状态扩展展示应用。当前硬编码解析值函数实验和网格标签拟合只是原型验证。

## 五、对我们此前工作的同样要求

- 433.4千美元依然没有与出版图匹配，不能以数值检验通过就宣告复现成功。
- 原生Fortran匹配“存档政策”不等于匹配“论文模型”。其EV递推的永久收入处理仍需单独解释。
- 我此前将cmin_grid=1描述为新修复不够准确：下载存档已是下界1；当时正式修改只是显式命名。零起点异常来自人为恢复零下界的对照实验，应按这个溯源表述。
- 207.7千美元来自此前Matlab历史政策转写的模拟，并非那一轮原生Fortran政策直接进入模拟器的新结果。
- 我上一轮对外部HARK包的介绍把部分“总结原论文扩展”的内容列成其已做实验，表述过宽，应区分原论文结果介绍与独立重算。

## 六、建议给老师的表述

> 目前完成了Matlab与Python两条离散时间实现，以及历史Fortran政策对照。Python初版的财富路径更接近出版图，但独立审查发现收入冲击相关性、归一化Euler条件和消费边界存在错误，尚不能据此判定此前Matlab结果错误。两版与出版结果的差异仍在核查。机器学习方面已完成Merton原型和生命周期政策的监督拟合，尚未完成完整连续时间生命周期问题的独立求解，也尚未完成有效高维状态下的性能比较。
